# 💧 Sistema de Monitoramento de Reservatório de Água
## 📋 Descrição do Projeto
Este repositório contém a resolução de uma atividade proposta, cujo objetivo é desenvolver um sistema simples de monitoramento de um reservatório de água.
O sistema foi elaborado para exibir no terminal mensagens de alerta com cores diferentes, conforme o nível de água identificado no reservatório.

## 🎯 Objetivo
Criar um programa simples e funcional que permita:

Representar os cinco níveis do reservatório em uma lista;
Associar cada nível a uma mensagem de alerta e uma cor específica;
Exibir as situações no terminal com destaque visual por cor.
